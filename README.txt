CM 27 — VERSION 0.8

FILES
- index.html: game interface
- style.css: original responsive styles
- script.js: V0.6 foundation and existing career systems
- v08.js: V0.8 expansion systems

HOW TO RUN
1. Extract the ZIP folder.
2. Keep all four files in the same folder.
3. Open index.html in Chrome or Edge, or use VS Code Live Server.
4. Existing V0.6 localStorage saves are read and upgraded with V0.8 data defaults.

V0.8 FEATURES
- Player nationality flags, profiles, fitness, fatigue and availability data.
- Maximum 25 registered players per club.
- Pre-match playing XI, captain and vice-captain selection.
- Tactical choices are applied to the match calculation.
- Separate club-owned stadium identity and capacity; coach upgrades disabled.
- Club finance dashboard, income/expense tracking and board-pressure consequences.
- Newsroom, weather reports, rain-reduced overs and pitch effects.
- Player debut and career-stat tracking.
- AI auction-round events and four-season mega-auction window.
- Retains existing V0.6 competitions, career, scouting, academy, transfers, media and save slots.

NOTES
This is a playable V0.8 foundation. Some advanced systems (full multi-franchise auction bidding, complete international calendar, full national-board simulation, realistic injury-duration model and detailed player-map artwork) are represented by initial connected systems and can be expanded in subsequent builds.
